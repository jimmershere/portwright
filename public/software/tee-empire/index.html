TeeEmpire

A multi-brand merch pipeline: concept, image, Printify mockups, a local approve-or-reject gate, then Etsy and social — only when you say live.

View on GitHub Ask Jimmer about it

How it runs

  1. 01

    Drop a prompt or a file

    The inbox takes an image or a prompt and plans a bundle — tee, mug, sticker, poster — from the brand’s lanes.

  2. 02

    Render, then look at the mockup

    A local Flask gate shows Printify mockups. You edit text, approve, or reject before anything leaves the machine.

  3. 03

    Ship only the yes

    Approved work can draft to Etsy and queue social posts for X, LinkedIn, Facebook, TikTok, and Instagram. Draft first. Live is a flag.

On purpose, it does not

It does not auto-publish. Dry-run is the default. Printify, Etsy, and PostBridge stay simulated until you pass --live.

  • Python
  • Flask review UI
  • SQLite
  • Printify
  • Etsy Open API
  • PostBridge

  • One input, a full bundle

    A single design can fan out across products instead of being redrawn per SKU.

  • Brand files, not one-off prompts

    Voice, palette, and shop ids live in YAML so a second brand is a config, not a rewrite.

  • Pluggable image backends

    KIE, OpenRouter, OpenAI, ComfyUI, or a local Pillow placeholder when you are just proving the path.
