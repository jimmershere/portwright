Talking cuts

ClemTock

Local vertical video of a cartoon that actually speaks your line. Lip sync, ad scripts, and an export — offline for the cartoon path, no API bill required.

View on GitHub Ask Jimmer about it

How it runs

  1. 01

    Write the line

    You supply the words. A local voice renders speech. Voice cloning asks for a clean sample and explicit consent.

  2. 02

    Mouth the cartoon

    Rhubarb drives pre-drawn mouth shapes. Missing shapes fall back instead of breaking the take.

  3. 03

    Cut a 1080×1920 file

    ffmpeg assembles the vertical video. A studio UI on port 3053 is there when the terminal is the wrong desk.

On purpose, it does not

The repo name stays ClemTock. Jimmer is the person on the studio site. Photoreal avatars are optional and external; the cartoon path does not need them.
