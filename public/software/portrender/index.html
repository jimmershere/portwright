Brand-aware renders

Portrender

One operator turns a brand prompt into images, approves or edits them, and hands the yes to TeeEmpire, ClemTock, or AU2. Portrender itself publishes nothing.

View on GitHub Ask Jimmer about it

How it runs

  1. 01

    Prompt from the brand file

    Templates plus a brand TOML — palette, voice, mascot notes — so the picture is not a one-off guess.

  2. 02

    Review like a contact sheet

    Terminal or browser: approve, reject, refine, restyle. Keyboard first. A spend counter sits in the open.

  3. 03

    Export the keepers

    Approved PNGs drop into the sibling tools with placement and category metadata. Nothing goes public from this step.

On purpose, it does not

It is not a storefront and not a social scheduler. It renders, reviews, and hands off. Spend is counted; it is not hidden.
